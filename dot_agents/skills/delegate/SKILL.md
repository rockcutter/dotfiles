# 作業の委譲

親エージェントは要件の解釈、ユーザーとの対話、計画、セキュリティ判断、成果物の検証・統合を担当する。独立した調査・実装・検証を worker に割り当てる。

## 開始前

- subagent 用のツールが利用可能か確認する。使えない場合はその旨を短く伝え、親が作業を続ける。
- 上位の指示やユーザーの制約を優先する。委譲によって commit・push の承認や機密ファイルの読み取り禁止を回避しない。
- 小さな編集や数回の検索で済む確認は親が直接行う。
- Claude Code の agent 名やモデル名を指定しない。通常は親のモデルを継承する。ユーザーがコスト削減を求める場合は、利用可能なモデルと指定可否を確認し、速度・料金の違いを未確認のまま断定しない。

## 割り当て

worker への指示には次を含める。

- 目的と背景
- 成果物の形式
- 対象範囲と編集可能なファイル
- 参照するパス
- 検証方法と完了条件

独立した作業だけを並列化し、同じファイルを複数の worker に同時編集させない。並列数は利用可能な枠に合わせる。会話履歴を共有できない場合は、必要な文脈を指示に含める。

## 検証と完了

- worker の調査結果は主要なファイル・関数を読み、根拠を確認する。
- 実装は diff を確認し、対象外の変更が混入していないか確認する。必要なテスト・リンターを実行する。
- 指示が曖昧なら具体化して再依頼する。繰り返し失敗する場合は親が引き取る。
- 完了報告には委譲した作業と検証結果を簡潔に記載する。
